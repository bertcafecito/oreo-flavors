# 🍪 Oreo Flavor Tasting

A community-maintained checklist and database of Oreo flavors from around the world.

The goal is simple: **discover, document, and taste as many Oreo flavors as possible.**

## What belongs here?

This repository is for documenting Oreo products and flavors, including:

- Current flavors
- Limited editions
- Seasonal flavors
- Regional/international flavors
- Discontinued flavors
- Special collaborations

This is the **master flavor list**. Personal tasting notes and ratings should live in your own tasting repository.
