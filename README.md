# 🍪 Oreo Flavor Tasting

A community-maintained checklist and database of Oreo flavors from around the world.

The goal is simple: **discover, document, and taste as many Oreo flavors as possible.**

## What belongs here?

This repository is for documenting Oreo products and flavors, including:

- Current flavors
- Limited editions
- Seasonal flavors
- Regional/international flavors
- Discontinued flavors
- Special collaborations

This is the **master flavor list**. Personal tasting notes and ratings should live in your own tasting repository.

## How to contribute

Found an Oreo flavor that isn't listed?

1. Fork this repository.
2. Create a branch for your addition.
3. Add the flavor to `FLAVORS.md`.
5. Include a source or evidence when possible.
6. Open a Pull Request.
7. Maintainers will review the submission.
8. Once approved, the flavor will be added to the master list.

Please read [`CONTRIBUTING.md`](CONTRIBUTING.md) before submitting.

## Flavor checklist

See [`FLAVORS.md`](FLAVORS.md) for the human-friendly checklist.

## Data guidelines

Please use the commonly recognized product/flavor name and avoid duplicate entries.

If a flavor has substantially different versions by country or release, document them separately when appropriate.
