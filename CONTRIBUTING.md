# Contributing

Thanks for helping build the Oreo flavor database! 🍪

## Adding a new flavor

Please use a Pull Request for all additions.

### 1. Fork the repository

Create your own fork on GitHub.

### 2. Create a branch

Use a descriptive branch name, for example:

```text
add-strawberry-oreo
```

### 3. Add the flavor

- `FLAVORS.md`

### 4. Provide evidence

A source is strongly encouraged. Good sources include:

- Manufacturer product pages
- Product packaging
- Retailer listings
- Reputable news or food publications
- Your own photograph of the packaging

If you personally found the product, explain where and when you found it.

### 5. Avoid duplicates

Search the repository before submitting a new flavor.

If the same flavor exists in another country or substantially different release, explain why it should be a separate entry.

### 6. Open a Pull Request

Your Pull Request should clearly explain:

- What flavor you are adding
- Where it is/was sold
- Whether it is limited edition
- Any known release information
- Your source/evidence

## Pull Request expectations

Please keep one flavor addition per Pull Request when practical. This makes reviewing and merging submissions easier.

Maintainers may edit formatting, correct duplicate entries, or request additional evidence.

Thank you for helping document Oreo flavors from around the world!
